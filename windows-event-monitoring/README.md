# Windows Event Monitoring with Sysmon and Splunk

## Overview / 概要

This project demonstrates centralized Windows event monitoring using Sysmon, Splunk Universal Forwarder, and Splunk Enterprise.

Windows endpoint telemetry is generated by Sysmon and forwarded to a centralized Splunk server running on Ubuntu Server.

---

## Architecture / 構成

```text
Windows Laptop
→ Sysmon
→ Splunk Universal Forwarder
→ Ubuntu Server
→ Splunk Enterprise
```

---

## Technologies Used / 使用技術

* Windows 11
* Sysmon
* Splunk Universal Forwarder
* Splunk Enterprise
* Ubuntu Server

---

## Objectives / 目的

* Collect Windows endpoint telemetry / Windowsテレメトリ収集
* Forward logs to a centralized SIEM / SIEMへのログ転送
* Monitor process creation activity / プロセス作成監視
* Analyze command-line execution / コマンドライン分析
* Create searchable security events / 検索可能なイベント作成

---

## Sysmon Installation / Sysmon導入

Sysmon was installed using Sysinternals Sysmon.

```powershell
sysmon64.exe -accepteula -i
```

---

## Splunk Forwarding / Splunk転送

Windows events are forwarded to Splunk Enterprise through Splunk Universal Forwarder.

```text
192.168.56.102:9997
```

---

## Sample Searches / 検索例

### Process Creation / プロセス作成

```spl
source="WinEventLog/Operational"
```

### Process Statistics / プロセス統計

```spl
source="WinEventLog/Operational"
| rex "Data Name='Image'>(?[^<]+)"
| stats count by Image
| sort -count
```

### Command Line Activity / コマンドライン監視

```spl
source="WinEventLog/Operational"
| rex "Data Name='Image'>(?[^<]+)"
| rex "Data Name='CommandLine'>(?[^<]+)"
| table _time Image CommandLine
```

Successfully collected and centralized Sysmon events from a Windows endpoint into Splunk Enterprise.
